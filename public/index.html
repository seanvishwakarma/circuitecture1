❓ FAQ

Frequently Asked Questions

Got questions about CircuitTecture? We have answers.

Do I need to install any software or drivers?
No! CircuitTecture runs 100% in your web browser. You can design, wire, code, and simulate microcontrollers instantly without installing any external compilers, drivers, or software packages.
Can I export my code to upload to a physical Arduino or ESP32?
Yes! You can download your written code as a standard `.ino` file for Arduino IDE or `.py` file for Thonny / MicroPython and flash it directly to real hardware.
What languages are supported in the circuit editor?
CircuitTecture supports both standard Arduino C/C++ and MicroPython, with real-time compilation and error checking directly in your browser.
Can teachers assign projects to students?
Yes! CircuitTecture includes a built-in Classroom Assignment module where educators can publish homework tasks, set due dates and rubrics, and grade student circuit submissions.
