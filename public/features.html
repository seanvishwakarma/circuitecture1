📡 Simulated Sensors

No Real Hardware Required

Every sensor in CircuitTecture is fully self-contained — adjust light levels, temperature, distance and more with built-in property sliders and canvas interactions.

  • ✓ MPU6050 accelerometer/gyroscope with animated drift
  • ✓ LDR photoresistor with adjustable light level
  • ✓ DHT22 temperature & humidity with slider control
  • ✓ Keyboard & mouse as digital interrupt sources
💻 Dual Code Engine

Arduino C++ & MicroPython

Write sketches in two of the most popular embedded languages. Our built-in transpiler converts your code into a simulation-ready AST and executes it statement-by-statement with full variable inspection.

  • ✓ Full Arduino API: digitalRead/Write, analogRead, Serial, Wire, SPI
  • ✓ MicroPython runtime with machine module emulation
  • ✓ Live syntax checking with inline error markers
  • ✓ Step-through debugger with variable watch panel
  • ✓ 20+ starter code templates included
// Weather Station — Arduino C++

#include <Wire.h>

📈 Signal Analysis

Multi-Channel Logic Analyzer

Capture and visualize digital and analog signal waveforms across multiple pins simultaneously. Spot timing issues, measure PWM duty cycles, and debug communication protocols in real-time.

  • ✓ Up to 8 simultaneous signal channels
  • ✓ PWM duty cycle & frequency measurement
  • ✓ SPI / I2C / UART protocol decode overlay
  • ✓ Adjustable timebase and trigger conditions
  • ✓ Export waveform data as CSV
🧩 Multi-Board Simulation

Run whole fleets of boards — linked

Drop a second Arduino, ESP32, Pico, or Raspberry Pi on the bench and every board runs its own sketch in parallel. Wire TX→RX to make them talk over UART, or link any pins to share digital signals across boards.

  • ✓ One sketch per board — board tabs above the editor
  • ✓ UART byte bridge across wired TX→RX pairs, with baud-mismatch warnings
  • ✓ Serial monitor, scope, watch & pinout panels all scoped per board
  • ✓ Perfect for sensor-hub → actuator-node class demos
