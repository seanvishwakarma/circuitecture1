Quick Start

CircuitTecture runs entirely in your web browser. No installation, no drivers, no configuration — just open the editor and start building.

💡CircuitTecture works best in Chrome, Edge, or Firefox. Safari is supported with some limitations on WebUSB features.

1. Open the Simulator

Navigate to circuittecture.local/editor or click "Launch Simulator" from the homepage. You'll see an empty circuit canvas with a component library on the left and a code editor on the right.

2. Add a Microcontroller

From the component library, search or browse for a board like Arduino Uno. Click it or drag it onto the canvas. The board appears with labeled pins ready for wiring.

3. Add Components & Wire

Add LEDs, sensors, displays, or motors the same way. To create a wire, click on any pin — it highlights green. Then click a second pin to complete the connection. Wires auto-route around components.

4. Write Your Code

In the right panel, select Code tab. Choose Arduino C++ or MicroPython. Write your sketch or pick a template from the Examples dropdown. The editor provides syntax highlighting, auto-indent, and live error checking.

5. Simulate

Click the ▶ Run button (or press Ctrl+Enter). Your code executes statement-by-statement. LEDs light up, servos move, and serial output appears in the Serial Monitor below the code editor.

Your First Circuit: Blink

The classic "Hello World" of electronics — blinking an LED on pin 13.

Circuit Setup

  • Drag an Arduino Uno onto the canvas
  • Drag an LED and a 220Ω Resistor
  • Wire: Uno pin 13 → Resistor → LED Anode
  • Wire: LED Cathode → Uno GND

Code

void setup() {
  pinMode(13, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(13, HIGH);
  Serial.println("LED ON");
  delay(1000);

  digitalWrite(13, LOW);
  Serial.println("LED OFF");
  delay(1000);
}

Press ▶ Run and watch the LED blink on the canvas while timestamps appear in the Serial Monitor.

Writing Code

CircuitTecture supports two programming languages:

  • Arduino C/C++ — Standard Arduino API with setup() and loop() lifecycle
  • MicroPython — Python-style syntax with machine module for GPIO, PWM, I2C, and SPI

Switch between languages using the dropdown in the Code panel header. Your code is auto-saved with the project.

🤖Use the AI Assistant tab to ask questions about your circuit or get code suggestions. It understands your current wiring and board configuration.

Arduino API Reference

CircuitTecture emulates the following Arduino core functions:

Digital I/O

pinMode(pin, mode)      // INPUT, OUTPUT, INPUT_PULLUP
digitalWrite(pin, val)  // HIGH or LOW
digitalRead(pin)        // Returns HIGH or LOW

Analog I/O

analogRead(pin)         // Returns 0–1023
analogWrite(pin, val)   // PWM output 0–255

Serial

Serial.begin(baud)
Serial.print(data)
Serial.println(data)
Serial.available()
Serial.read()

Time

delay(ms)
delayMicroseconds(us)
millis()
micros()

Advanced

tone(pin, frequency, duration)
noTone(pin)
pulseIn(pin, value)
shiftOut(dataPin, clockPin, bitOrder, value)
Wire.begin() / Wire.write() / Wire.read()
SPI.begin() / SPI.transfer()

MicroPython API Reference

from machine import Pin, PWM, ADC, I2C, SPI
import time

# Digital output
led = Pin(13, Pin.OUT)
led.value(1)

# Analog read
adc = ADC(Pin(34))
val = adc.read()

# PWM
pwm = PWM(Pin(25), freq=1000, duty=512)

# I2C
i2c = I2C(0, scl=Pin(22), sda=Pin(21))
i2c.scan()
i2c.writeto(0x3C, b'\x00')

# Timing
time.sleep(1)
time.sleep_ms(500)
time.ticks_ms()

Pinout Reference

Each microcontroller board in CircuitTecture displays its full pin layout directly on the canvas. Hover any pin to see its name, type (digital/analog/PWM/I2C/SPI), and supported functions.

Arduino Uno R3

  • Digital pins: D0–D13 (D3, D5, D6, D9, D10, D11 support PWM)
  • Analog pins: A0–A5
  • I2C: SDA (A4), SCL (A5)
  • SPI: MOSI (D11), MISO (D12), SCK (D13), SS (D10)
  • Serial: TX (D1), RX (D0)
  • Power: 5V, 3.3V, GND, VIN

ESP32 WROOM

  • GPIO: GPIO0–GPIO39 (most support digital, ADC, PWM, touch)
  • I2C: Default SDA (GPIO21), SCL (GPIO22)
  • SPI: VSPI and HSPI with configurable pins
  • Serial: UART0 (GPIO1/3), UART1, UART2
  • DAC: GPIO25, GPIO26

Simulated Sensors

CircuitTecture's components are fully self-contained — no real hardware needed:

  • MPU6050 (IMU): Simulated accelerometer/gyroscope with gentle animated drift, ready to use without any device permissions.
  • LDR / Photoresistor: Light level adjustable via a slider on the component properties panel.
  • All other sensors (DHT22, ultrasonic, PIR, soil moisture, gas, IR obstacle) use property sliders or canvas interactions to produce realistic values.

Logic Analyzer

The built-in logic analyzer captures digital and analog signals in real-time during simulation. Open it from the Scope tab in the right dock.

  • Add channels by selecting pins from the dropdown and clicking + channel
  • Supports up to 8 simultaneous channels
  • Adjustable timebase and vertical scale
  • Hover to inspect exact voltage/timing at cursor position

Sharing & Exporting

Share a Project

Click 🔗 Share in the editor toolbar. This generates a unique URL that anyone can use to view your circuit (read-only). They can fork it to create their own editable copy.

Export Code

Click ⬇ Export in the code panel header to download your sketch as a .ino (Arduino) or .py (MicroPython) file, ready to upload to physical hardware.

Troubleshooting

Simulation won't start

  • Check the Problems panel for syntax errors in your code
  • Make sure you have a board on the canvas — the simulator needs at least one microcontroller
  • Try refreshing the browser page

Wires won't connect

  • Make sure you're clicking directly on a pin (it highlights green when hoverable)
  • Some pins may already be connected — check the Inspector panel
  • Enable Snap to grid for easier pin targeting

A sensor isn't responding

  • Check the sensor's property panel — most sensors have sliders to control their output level
  • Make sure VCC and GND are wired
  • For I2C sensors (OLED, MPU6050), confirm SDA and SCL are connected
  • Try pressing ▶ Run to start the simulation
